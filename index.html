업로드 순서

  1. 아두이노 IDE 실행 → 도구 > 보드: Arduino Uno
  2. 도구 > 포트: 오렌지보드 COM 포트 선택
  3. 오른쪽 코드를 복사해 붙여넣고 업로드 (추가 라이브러리 설치 불필요)
  4. 업로드 후 시리얼 모니터는 반드시 닫기 (열려 있으면 웹앱이 연결할 수 없음)
  5. 측정하기 탭 → USB 연결 → 포트 선택
포트가 보이지 않으면 오렌지보드의 USB 칩(CH340) 드라이버를 설치해야 할 수 있습니다. 데이터 전송이 되는 USB 케이블인지도 확인하세요.

수업 진행 방법

    
    
      
  1. 센서를 배선한 뒤 아두이노 코드를 업로드합니다. 센서는 테이프나 밴드로 손목, 허리, 발목 중 한 곳에 단단히 고정합니다.
    2. 
      
  2. USB 연결을 누르고 포트를 선택합니다. 상단 상태가 초록색 “수신 중”이 되면 준비 완료입니다.
    3. 
      
  3. 센서를 가만히 둔 상태에서 영점 조정을 한 번 누릅니다. (정지 상태의 값을 0으로 맞춥니다.)
    4. 
      
  4. 학생 정보를 입력하고 측정 시작을 누르면 3초 카운트다운 후 10초 동안 자동 측정됩니다. 도중에 측정 종료를 누르면 그때까지의 기록으로 분석합니다.
    5. 
      
  5. 결과는 자동 저장되고, 순위 · 기록 탭에서 학생별 최고점 순위를 확인할 수 있습니다.
    6. 
      
  6. 분석표 PDF 저장 · 인쇄를 누르고 인쇄 창에서 대상(프린터)을 “PDF로 저장”으로 고르면 PDF 파일로 저장되고, 프린터를 고르면 바로 인쇄됩니다.
    7. 
    

  

  

    
분석 지표 설명

    

      
지표의미

      
움직임 크기 (g)가속도 크기에서 중력(1g)을 뺀 값입니다. 가만히 있으면 0에 가깝고, 세게 움직일수록 커집니다.

      
최고 움직임 점수측정 시간 중 가장 큰 움직임 크기 × 100입니다. 순위의 기준이 됩니다.

      
운동량 점수움직임 크기를 시간에 따라 누적한 값(g·초 × 100)입니다. 쉬지 않고 많이 움직일수록 커집니다.

      
회전 속도 (°/s)자이로센서가 측정한 1초당 회전 각도입니다. 팔 돌리기, 몸 비틀기 등에서 커집니다.

      
동작 횟수움직임 크기가 0.5g를 넘은 횟수입니다 (0.25초 이내 중복 제외). 점프, 스쿼트 횟수 등과 비교해 볼 수 있습니다.

      
강도 분포정지(<0.1g), 가벼움(0.1~0.5g), 보통(0.5~1.0g), 격렬(≥1.0g)으로 나누어 각 강도로 움직인 시간 비율을 보여 줍니다.

    

  

  

    
연결 문제 해결

    

      
증상해결 방법

      
포트 선택 창에 보드가 없음CH340 드라이버 설치, 데이터 전송용 USB 케이블 사용, 다른 USB 포트에 꽂기

      
“포트를 열 수 없음”아두이노 IDE의 시리얼 모니터나 시리얼 플로터, 다른 탭의 웹앱이 포트를 쓰고 있는지 확인하고 닫기

      
연결됐지만 “데이터 없음”코드 업로드 여부 확인, 통신 속도 115200 확인, 배선 확인 (SCL→A5, SDA→A4)

      
“센서를 찾을 수 없음”VCC와 GND 연결, 점퍼선 접촉 상태 확인 (2초마다 자동으로 다시 시도함)

      
측정 중 USB가 빠짐그때까지의 데이터로 결과를 저장합니다. 다시 꽂으면 자동으로 다시 연결됩니다.

      
그래프가 끊김센서 선이 길거나 흔들리면 I2C가 불안정해집니다. 선을 짧게 하고 테이프로 고정하세요. 오류가 나면 코드가 센서를 자동으로 다시 초기화합니다.
